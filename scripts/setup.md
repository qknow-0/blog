# 新机初始化脚本

换电脑时运行 `./scripts/setup.sh`，自动检测并安装缺失的工具。已安装的自动跳过，可重复执行。

## 安装清单

| 工具 | 分类 | 安装方式 |
|------|------|------|
| Homebrew | 基础 | 官方脚本 |
| Git | 基础 | brew |
| OrbStack | 容器 | brew |
| Docker CLI | 容器 | brew |
| Zed | 编辑器 | brew cask |
| Claude Code | AI 助手 | 官方脚本 |
| Orca | AI 助手 | brew cask |
| uv | 包管理 | 官方脚本 |
| Bun | 运行时 | 官方脚本 |
| RTK | AI 工具 | 官方脚本 |
| ccstatusline | AI 工具 | git clone + setup |
| agentmemory | AI 工具 | git clone |
| CodeGraph | AI 工具 | npm install -g |
| Compound Engineering | AI 工具 | npx skills add |
