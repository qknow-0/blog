# 新机初始化脚本

换电脑时运行 `./scripts/setup.sh`，自动检测并安装缺失的工具。已安装的自动跳过，可重复执行。

## 安装清单

| 工具 | 分类 | 安装方式 |
|------|------|------|
| Homebrew | 基础 | 官方脚本 |
| Git | 基础 | brew |
| Zed | 编辑器 | brew cask |
| Claude Code | AI 助手 | 官方脚本 |
| uv | 包管理 | 官方脚本 |
| Bun | 运行时 | 官方脚本 |
| Spec-Kit | AI 工具 | uv tool |
| gstack | AI 工具 | git clone + setup |
| RTK | AI 工具 | 官方脚本 |
| code-review-graph | AI 工具 | pip |
| ccstatusline | AI 工具 | git clone + setup |
| agentmemory | AI 工具 | git clone |
