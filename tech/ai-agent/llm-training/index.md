# 大模型是如何训练的——用最简单的比喻

五篇系列，每篇聚焦一个训练阶段。不需要数学基础，每篇有一个核心比喻，看完能向任何人讲清楚大模型是怎么「学会」的。

## 阅读顺序

1. **[（一）数据：把整个互联网倒进锅里](01-data.md)** — 2026-06-11
   - 训练数据是模型的「食谱」——吃什么长什么。数据清洗、去重、配比的完整流程

2. **[（二）预训练：做几十亿道完形填空](02-pretraining.md)** — 2026-06-11
   - 把整段文字挖掉一个词让模型猜。猜错调参数。几十亿遍后模型学会了语言的统计规律

3. **[（三）微调：从接话机变成会聊天的人](03-finetuning.md)** — 2026-06-11
   - 预训练出来的是「补全狂魔」，微调用对话样例教它回答问题的方式

4. **[（四）RLHF：人类老师打分，模型改作业](04-rlhf.md)** — 2026-06-11
   - 给两个回答打分，模型从偏好里学行为。就像驯狗——做对了给零食

5. **[（五）推理：一个字一个字往外蹦](05-inference.md)** — 2026-06-11
   - 训练完了，推理时算法不变。温度参数控制「创造力」，和预训练做的事情完全一样

6. **[（六）实战：300 行代码训一个能讲莎士比亚的小 GPT](06-practical.md)** — 2026-06-11
   - 亲手用 PyTorch 从零搭一个微型 GPT，在自己的电脑上跑 10 分钟，生成莎士比亚风格的文本
