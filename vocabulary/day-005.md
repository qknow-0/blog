# Day 005 — 2026-05-30

## 1. Throughput /ˈθruːpʊt/（吞吐量）

单位时间内系统处理的工作量。数据库用 QPS（每秒查询数），网络用 bps（每秒比特数），消息队列用 msg/s。高吞吐和低延迟是两回事——批处理增加吞吐但也增加单次延迟。

## 2. Encapsulation /ɪnˌkæpsjuˈleɪʃən/（封装）

将数据和操作数据的方法绑定在一起，隐藏内部实现只暴露公开接口。面向对象的核心三原则之一（封装、继承、多态）。Rust 用 `pub` 关键字控制可见性，模块边界是封装的基本单元。

## 3. Polymorphism /ˌpɒlɪˈmɔːrfɪzəm/（多态）

同一个接口接受不同数据类型。Rust 通过 trait 实现静态多态（编译期单态化），Java 通过继承实现动态多态（运行时虚表派发）。泛型也是多态的一种形式——参数多态。

## 4. Artifact /ˈɑːrtɪfækt/（制品/产出物）

构建过程产生的文件。CI/CD 中的 artifact 包括编译好的二进制、Docker 镜像、测试报告、覆盖率文件。GitHub Actions 的 `upload-artifact` 将构建产物传递给后续 job。

## 5. Scaffolding /ˈskæfəldɪŋ/（脚手架）

自动生成项目初始结构。`npm create vite`、`cargo init`、Rails 的 `scaffold` 命令都生成模板化的目录、配置和初始代码。好的脚手架让你一分钟进入编码，而不是十分钟配环境。

## 6. Bootstrapping /ˈbuːtstræpɪŋ/（引导/自举）

系统靠自身初始化自身的过程。Rust 编译器用 Rust 写，第一个版本用 OCaml 写，之后用 Rust 自己编译自己——这就是自举。K8s 的 bootstrapping 节点先启动控制面组件再加入自身为 worker。

## 7. Heuristic /hjuˈrɪstɪk/（启发式方法）

不保证最优解但实际可用的近似方法。编译器的分支预测、数据库的查询优化器选执行计划、AI Agent 的工具选择决策树——都是 heuristic——不求完美，但求大概率正确。

## 8. Cohesion /koʊˈhiːʒən/（内聚）

模块内部元素之间关联的紧密程度。高内聚的模块做一件事且只做一件事——函数所有行服务于同一目标，类的所有方法围绕同一数据。低内聚是"万能工具类"，什么都有但什么都不精。高内聚低耦合是好架构的黄金标准。

## 9. Coupling /ˈkʌplɪŋ/（耦合）

模块之间互相依赖的程度。紧耦合修改一个模块必改另一个，松耦合通过接口约定各自独立演化。微服务之间通过消息队列异步通信是松耦合，共享数据库是紧耦合。

## 10. Ephemeral /ɪˈfemərəl/（短暂/临时的）

存在时间很短的东西。Docker 容器应该是 ephemeral 的——随时销毁重建不留状态。Serverless 函数实例也是 ephemeral 的——调完即消失。Ephemeral 存储（如 `/tmp`）重启即清空。
