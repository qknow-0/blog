# Day 007 — 2026-06-16

## 1. Idempotent /ˌaɪdɛmˈpoʊtənt/（幂等的）

同一个操作执行多次和执行一次产生相同效果。HTTP PUT 是幂等的，POST 不是。分布式系统中重试安全性往往取决于操作是否幂等。

## 2. Serialization /ˌsɪriəlaɪˈzeɪʃən/（序列化）

把内存中的数据结构转换成可存储或可传输的字节序列的过程。JSON、Protobuf、MessagePack 都是序列化方案。对应的反向操作是 Deserialization（反序列化）。

## 3. Descriptor /dɪˈskrɪptər/（描述器）

Python 中实现了 `__get__`、`__set__`、`__delete__` 协议的对象。`property`、`classmethod`、`staticmethod` 底层都是描述器，它控制了对象属性访问的全流程。

## 4. Trait /treɪt/（特质）

Rust 和 Scala 中定义共享行为的抽象机制。Rust 的 trait 类似其他语言的接口（interface），但可以包含默认实现，且支持泛型约束（trait bound）。组合优于继承在 trait 系统里体现得最彻底。

## 5. Coercion /koʊˈɜrʒən/（强制类型转换）

编译或运行时自动进行的隐式类型转换。Rust 有 Deref coercion、lifetime coercion 等受限的隐式转换；JavaScript 则有大量令人意外的 coercion（`[] + {}` 等）。显式优于隐式是 Rust 的核心哲学。

## 6. Ownership /ˈoʊnərʃɪp/（所有权）

Rust 的核心内存管理机制：每个值只有一个所有者，所有者离开作用域时值被释放。没有 GC、没有手动 free，编译期通过借⽤检查器（borrow checker）保证内存安全。

## 7. Polymorphism /ˌpɑliˈmɔrfɪzəm/（多态）

同一接口对不同数据类型产生不同行为的能力。Rust 中主要有两种：静态多态（泛型 + trait bound，编译期单态化）和动态多态（`dyn Trait`，运行期虚表分发）。Python 鸭子类型是另一种多态。

## 8. Concurrency /kənˈkɜrənsi/（并发）

多个任务在重叠时间段内执行，但不一定同时。asyncio、goroutine、线程都是并发模型。并发解决的是程序结构问题（如何组织 I/O 密集型任务），并行才是 CPU 密集型性能问题。

## 9. Middleware /ˈmɪdlˌwɛr/（中间件）

处理请求/响应管道的可组合组件，每个中间件可以在请求到达最终处理器前后执行逻辑。Express、Django、Actix 都采用这种模式，本质是 Chain of Responsibility 的现实实现。

## 10. Orthogonal /ɔrˈθɒɡənəl/（正交的）

两个概念互不干扰，可以独立变化。语言特性正交意味着不存在需要特殊处理的交叉情况；API 设计正交意味着每个功能只做一件事。正交性是衡量设计质量的试金石。
