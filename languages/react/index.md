# React 系列

> 本文系列基于 React 19.2（2026 年 6 月最新稳定版），涉及版本特性会标注最低支持版本。

React 不是一个「学习一次，到处写代码」的库——它是一个围绕声明式 UI、单向数据流、组件化构建的思想体系。这个系列不逐行翻译文档，而是从设计决策的角度理解 React：为什么这样设计、不这样会有什么问题。
