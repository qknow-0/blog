# C++ 面向对象系列

C++ 的面向对象不只是 `class` 加继承。真正难的是三件事：怎么把不变量守住、什么时候该用继承、以及怎么让自定义类型用起来像内置类型。

这三篇从「封装与接口」讲到「继承的边界」，最后落到「运算符重载」，把语法背后的设计取舍串起来。所有示例基于 C++23。

## 阅读顺序

1. **[（一）封装与接口：把“能做什么”和“怎么做”分开](01-encapsulation.md)** — 2026-11-16
   - 不变量与访问控制、接口设计、pimpl 编译防火墙、NVI（public 非虚 / private 虚）

2. **[（二）继承的边界：is-a 不是万能钥匙](02-inheritance.md)** — 2026-11-16
   - 三种继承方式、构造/析构顺序、名字隐藏、多重继承与菱形、组合优于继承、LSP

3. **[（三）运算符重载：让自定义类型说人话](03-operator-overloading.md)** — 2026-11-16
   - 成员 vs 非成员、算术运算符、C++20 比较运算符、流运算符、转换运算符、常见坑
